# Baby Express 프로젝트 메모

이 폴더는 Baby Express 프로젝트의 공식 메모입니다.

- 작업 시작과 메모 관리 기준은 [GUIDELINE.md](GUIDELINE.md)를 따릅니다.
- 전체 진행 단계는 [ROADMAP.md](ROADMAP.md) / 현재 우선순위는 [TODO.md](TODO.md)에서 확인합니다.
- 프로젝트 전역 기획과 시스템 경계는 [DECISION.md](DECISION.md)를 기준으로 판단합니다.
- 시스템별 상세 기획은 [System](System) 폴더 / 실제 구현 완료 상태는 [DONE.md](DONE.md)에서 확인합니다.
- 진행을 실제로 막았던 오류는 [ERROR.md](ERROR.md)에서 관리합니다.
- 이 폴더의 Markdown 문서만 공식 메모로 사용하며 TXT 또는 외부 백업 문서는 작업 기준으로 사용하지 않습니다.
