# SETTINGS

## PURPOSE

타이틀과 플레이 화면에서 공통으로 사용하는 오디오 / 화면 설정과 적용 / 취소 범위를 관리한다.

* 실제 구현 완료 상태는 [DONE.md](../DONE.md)를 기준으로 확인한다.
* 설정 저장 계층은 [SAVE_LOAD.md](SAVE_LOAD.md)와 연결하되 저장 방식 확정 전까지 UI와 적용 구조에 결합하지 않는다.

## CONTENTS

설정 시스템 내부 목차

* MVP 설정 항목

* 저장 보류
* 구현 계획 / 검증

## CONFIRMED

### MVP 설정 항목

* 오디오는 Master Volume / BGM Volume / SFX Volume과 각 항목의 음소거를 제공한다.
* 배경 음악은 타이틀 / 플레이 / 이벤트 세 종류를 사용하고 씬 전환 시 현재 장면 음악을 선택한다. 같은 음원이 이미 재생 중이면 처음부터 다시 재생하지 않으며 이벤트 종료 후 현재 장면 음악으로 복구한다.
* 효과음은 버튼 / 패널 / 파츠 / 안착 / 대화 / 자금 / 구매 / 판매 / 성공 / 실패 / 거부 / 경고 / 업적 / 보상 종류로 구분하고 같은 음원을 여러 기능에서 재사용할 수 있다.
* 화면은 전체화면 여부 / 해상도를 제공한다.
* 위 항목 외 설정은 MVP 이후 확장 범위로 둔다.

### 적용값과 편집값

* 설정 화면 진입 시 현재 실제 적용값을 UI 편집값으로 복사한다.
* 오디오의 볼륨과 음소거 조작은 편집값만 변경하고 적용 버튼을 눌렀을 때 실제 적용값으로 확정한다.
* 오디오 음소거 상태와 슬라이더 값은 따로 보관하며 음소거를 해제하면 음소거 전 슬라이더 음량으로 복구한다.
* 적용하지 않고 닫으면 오디오 편집값을 폐기하며 다시 열었을 때 기존 실제 적용값을 표시한다.
* 화면 설정은 잘못된 해상도나 화면 모드로 조작 불가능해지는 상황을 막기 위해 오디오와 다른 임시 적용 규칙을 사용한다.

### 화면 설정 임시 적용

* PC에서 창 모드 / 전체 화면 또는 해상도를 선택하면 메인 적용 버튼을 누르지 않아도 선택값을 즉시 임시 적용한다.
* 임시 적용 직전의 마지막 확정 화면 설정을 복구 원본으로 별도 보관한다.
* 임시 적용과 동시에 확인 창과 10초의 남은 시간을 표시하며 제한 시간 안에 확인을 눌러야 선택한 화면 설정을 확정한다.
* 확인하지 않고 제한 시간이 끝나거나 확인 창에서 취소하면 창 모드와 해상도를 모두 마지막 확정값으로 복구한다.
* 확인 창이 열린 상태에서 설정 화면을 닫는 경우에도 미확정 화면 설정을 유지하지 않고 마지막 확정값으로 복구한다.
* 화면 설정 확인 제한 시간은 10초를 사용하며 새 화면 후보를 선택하면 기존 확인 시간을 취소하고 10초부터 다시 시작한다.

### 플랫폼별 화면 UI

* PC에서는 창 모드 / 전체 화면과 해상도 설정을 모두 표시한다.
* Android / iOS 모바일 빌드에서는 창 모드와 해상도 설정이 필요하지 않으므로 두 입력 항목과 연결된 아이콘 / 라벨을 표시하지 않는다.
* 모바일에서 화면 설정 UI를 숨겨도 오디오 설정 / 적용 / 취소 흐름은 그대로 제공한다.

### 공용 화면

* Title과 Play는 같은 `SettingsView` 구조와 같은 설정 규칙을 사용한다.
* 각 씬에 View 인스턴스가 따로 있어도 같은 런타임 설정 원본을 조회해 한 실행 안에서 적용값을 유지한다.
* 설정 화면을 닫아도 메인 화면 상태나 날짜 진행을 변경하지 않는다.

### 저장

* PlayerPrefs / 별도 설정 파일 / 세이브 데이터 통합 중 어떤 방식을 사용할지는 보류한다.
* 런타임 설정 / 실제 적용 / UI 편집 / 영구 저장 책임을 분리해 저장 방식이 바뀌어도 View와 적용 로직을 다시 만들지 않는다.

## DATA

### SettingsValue

* Master / BGM / SFX 볼륨과 각 음소거 여부 / 전체화면 여부 / 해상도 너비와 높이를 가진다.

### SettingsModel

* 현재 실제 적용값을 보관하고 Title과 Play에서 같은 런타임 원본을 사용한다.
* 설정값 변경 성공 시 적용된 값만 갱신한다.

### SettingsEditState

* 화면 진입 시 `SettingsModel`의 적용값을 복사한 임시 편집 상태이다.
* 닫기 또는 취소 시 폐기하고 적용 성공 시 새 적용값으로 다시 동기화한다.
* 화면 설정 임시 적용 중에는 편집 후보와 마지막 확정 화면 설정을 구분해 시간 초과 / 취소 시 복구할 수 있어야 한다.
* 화면 설정 복구 시 오디오 편집값은 유지하고 화면 모드와 해상도만 마지막 확정값으로 되돌린다.

### AudioClipMap

* `BGMType` / `SFXType`과 `AudioClip` 대응을 보관하는 음원 참조의 단일 원본이다.
* `AudioManagerData`는 AudioMixer / BGM·SFX MixerGroup / `AudioClipMap` 참조만 제공하고 개별 음원을 중복 보관하지 않는다.
* 음원 종류 조회는 항목 수가 적은 현재 범위에서 배열 선형 검색을 사용하고 미등록 종류는 재생하지 않는다.

## MVP_RESPONSIBILITY

* `SettingsPresenter`는 화면 진입 / 오디오 편집과 적용 / 화면 임시 적용 / 확인 제한 시간 / 복구 / 닫기 흐름을 중재한다.
* `SettingsView`는 슬라이더 / 음소거 토글 / 화면 모드 / 해상도 / 적용 / 닫기 입력과 화면 설정 확인 창 / 남은 시간을 표시한다.
* `SettingsApplier`는 `AudioManager`에 오디오 적용을 요청하고 `Screen` API로 화면 설정의 임시 적용 / 확정값 복구를 실행하며 View와 저장 방식을 참조하지 않는다.
* `AudioManager`는 AudioMixer / BGM과 SFX AudioSource / 장면과 이벤트 BGM 상태 / 공용 UI 효과음 재생 / Master / BGM / SFX 볼륨과 음소거의 실제 적용을 담당하고 개별 음원 참조는 `AudioClipMap`에서 조회한다.
* `SettingsManager`는 현재 확정된 설정값과 편집 상태 생성을 관리하며 AudioMixer와 AudioSource를 직접 소유하지 않는다.
* 메인 적용 버튼은 오디오 편집값만 확정하고 화면 설정은 임시 적용 확인 창의 확인 입력으로 별도 확정한다.
* 저장 계층은 이후 확정된 적용값을 불러오고 저장하는 Adapter로 연결한다.

## IMPLEMENTATION_STATUS

* 공용 `SettingsModel` / `SettingsEditState` / `SettingsManager`와 오디오와 화면 적용 기본 구조를 구현했다.
* `AudioManager`를 설정 관리와 분리하고 BGM / SFX 재생 / 공용 UI 효과음 / Mixer 적용 책임을 이동했다.
* `AudioClipMap`과 `BGMType` / `SFXType`을 구현하고 타이틀 / 플레이 장면 BGM 자동 전환 / 이벤트 BGM 복구 / 같은 BGM 재시작 방지 / 공용 버튼과 패널 효과음 연결을 사용자 Play Mode에서 확인했다.
* Master / BGM / SFX 볼륨 조절과 개별 음소거는 사용자 Play Mode에서 정상 적용을 확인했다.
* 화면 모드와 해상도 선택 즉시 임시 적용 / 확인 창 / 10초 제한 시간 / 확인 확정 / 취소와 시간 초과 및 화면 닫기 복구를 구현했다.
* 모바일에서는 화면 설정 그룹을 숨기고 화면 설정 흐름에 진입하지 않도록 구현했다.
* 사용자 Play Mode에서 화면 설정 Dropdown 변경 시 확인 창 표시와 확인 입력 시 오류가 없음을 확인했으며 실제 창 모드 / 해상도 변경과 시간 초과 복구 / 모바일 표시는 실행 파일과 실기기에서 추가 검증한다.

## IMPLEMENTATION_PLAN

1. PC 실행 파일에서 창 모드와 전체 화면 / 지원 해상도 조합 / 확인 / 취소 / 시간 초과 복구 / 재진입 표시를 검증한다.
2. 모바일 빌드에서 화면 설정 그룹이 숨겨지고 오디오 설정만 정상 동작하는지 검증한다.
3. Title에서 확정한 오디오와 화면 설정이 Play에서도 유지되는지 검증한다.
4. 저장 방식이 확정되면 `SettingsModel` 앞뒤에 불러오기 / 저장 Adapter만 연결한다.
5. 런타임 생성 버튼의 공용 클릭음 등록 / 패널 연속 입력 효과음 중복 / 기능별 성공·실패 효과음 호출을 검증한다.
