# ROADMAP

## PURPOSE

전체 MVP 진행 단계와 현재 작업 위치를 관리한다.

* 현재 우선순위는 [TODO.md](TODO.md) / 전역 기획과 시스템 경계는 [DECISION.md](DECISION.md) / 시스템별 상세는 System 폴더 / 구현 완료 근거는 [DONE.md](DONE.md)에서 관리한다.
* 이 파일에는 전체 흐름을 파악하는 데 필요한 시스템 단위 상태만 기록한다.

## CURRENT_PHASE

전체 진행 상태

* 전체 MVP 예상 진행률: 약 92%
* 현재 단계: Play 씬 기본 루프와 UI 전면 교체 / 인트로 / Day 1 핵심 튜토리얼 / Day 2~7 조건형 가이드 / 직원 8종 데이터와 효과 코드 연결 완료
* 현재 목표: 듀라한으로 대표 확인한 직원 효과를 기준으로 나머지 7종 효과와 저장 복구를 통합 검증한다. 이후 제작 파츠 회전·좌우 반전과 잔여 데이터·UI를 마무리한다. 상세 순서는 [TODO.md](TODO.md)의 `CURRENT_TODO`를 따른다.

## UPDATE_RULE

갱신 기준

* 시스템 단계가 시작 / 1차 완료 / 보류로 바뀔 때만 현재 단계와 진행 상태를 갱신한다.
* 세부 함수 / 경계 테스트 / 날짜별 완료 내역은 기록하지 않는다.
* 완료 상태는 [DONE.md](DONE.md)의 실제 구현과 검증 결과를 기준으로 판단한다.
